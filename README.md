# محاسبي — برنامج المحاسبة الشخصية والمهنية

برنامج ويب عربي بالقيد المزدوج يجمع مالك الشخصي وعملك الحر في دفتر واحد: سندات وقيود، صناديق وبنوك وبطاقات، ديون لك وعليك بالأقساط، تقارير مالية، وإدارة كاملة للنظام.

**التقنيات:** Next.js 14 + Supabase (Postgres) + Tailwind. المنطق المحاسبي كله داخل قاعدة البيانات (دوال وقيود وحمايات)، فلا يمكن لأي واجهة أو طلب مباشر أن يكسر توازن الدفتر.

---

## التشغيل لأول مرة (حوالي 15 دقيقة)

### 1) قاعدة البيانات على Supabase
1. أنشئ مشروعاً جديداً في [supabase.com](https://supabase.com) (اختر منطقة قريبة، مثل Frankfurt أو Mumbai).
2. من **SQL Editor ← New query** الصق محتوى الملف `supabase/setup.sql` كاملاً واضغط **Run**. يجب أن تظهر رسالة نجاح بلا أخطاء.
3. من **Authentication ← URL Configuration**:
   - **Site URL:** رابط موقعك (مثلاً `https://mahasi.vercel.app`)، وأثناء التجربة المحلية `http://localhost:3000`.
   - **Redirect URLs:** أضف `https://رابطك/auth/callback` و `http://localhost:3000/auth/callback`.
4. (اختياري) إن أردت الدخول فوراً بلا رسالة تأكيد بريد: **Authentication ← Providers ← Email** وألغِ «Confirm email».
5. من **Project Settings ← API** انسخ: `Project URL` و `anon public key`.

### 2) التشغيل على جهازك
```bash
npm install
cp .env.example .env.local      # ثم الصق القيمتين من Supabase
npm run dev                      # افتح http://localhost:3000
```

### 3) النشر على Vercel
1. ارفع المجلد إلى مستودع GitHub خاص.
2. في Vercel: **Add New Project** ← اختر المستودع.
3. أضف متغيرَي البيئة `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` ← **Deploy**.
4. حدّث **Site URL** و **Redirect URLs** في Supabase برابط Vercel النهائي.

> التحديثات اللاحقة لقاعدة البيانات ستأتي كملفات جديدة في `supabase/migrations/` تشغّلها بالترتيب في SQL Editor.

## ما يحتويه البرنامج (المرحلة الأولى)

| الوحدة | المحتوى |
|---|---|
| **دليل الحسابات** | نحو 95 حساباً جاهزاً بأربعة مستويات يفصل الشخصي عن العمل الحر؛ إضافة وتعديل وتعطيل، والأرصدة تُجمع للآباء |
| **السندات** | مصروف، دخل، قبض، صرف، تحويل بين الصناديق (حتى بعملتين)، قيد يومية حر؛ بنود متعددة، مسودات، قوالب، نسخ، عكس، طباعة بالتفقيط والتاريخ الهجري |
| **الصناديق والبنوك** | نقد، بنوك، محافظ إلكترونية، بطاقات ائتمان؛ منع الرصيد السالب؛ كشف لكل صندوق بعملته |
| **الديون** | لك وعليك، دفعة واحدة أو أقساط (شهري/أسبوعي/ربعي/سنوي)، سداد جزئي يُوزَّع على الأقدم، إعادة جدولة، إبراء (هبة أو معدوم)، فروق العملة المحققة، تقويم الاستحقاقات، تذكير واتساب |
| **الأشخاص والجهات** | عملاء، موردون، أقارب، أصدقاء؛ رصيد صافٍ واحد لكل شخص؛ كشف حساب؛ إرسال الرصيد بواتساب |
| **التقارير** | ميزان المراجعة، قائمة الدخل (عمل حر / شخصي / مشترك)، المركز المالي وصافي الثروة، تحليل المصروفات، ربحية المشاريع، حركة الصناديق، أعمار الديون، كشف أي حساب أو شخص أو مشروع — كلها تُطبع وتُصدَّر إلى Excel |
| **إدارة النظام** | إعدادات الدفتر، المستخدمون بأربع صلاحيات (مالك، مدير، محاسب، مطّلع)، العملات وأسعار الصرف (الريال اليمني بسعري عدن وصنعاء)، مراكز التكلفة والمشاريع، إقفال الفترات، القوالب، سجل تدقيق كامل، نسخة احتياطية JSON وتصدير Excel |
| **الواجهة** | عربية بالكامل، وضع ليلي، وضع خصوصية يخفي الأرقام، تصميم للجوال بشريط سفلي وزر إضافة، اختصار N لعملية جديدة، دفاتر متعددة لكل مستخدم |

### الضمانات المحاسبية (مفروضة داخل قاعدة البيانات)
- لا يُرحَّل قيد غير متوازن، ولا قيد على حساب رئيسي أو معطّل.
- القيد المرحّل لا يُعدَّل ولا يُحذف؛ التصحيح بقيد عكسي مرتبط بالأصل.
- ترقيم تسلسلي بلا فجوات لكل نوع سند ولكل سنة مالية (مثل `RV-2026-00012`).
- تاريخ إقفال يمنع أي ترحيل أو عكس في الفترات المراجَعة.
- كل دفتر معزول تماماً عن غيره بسياسات أمان الصفوف (RLS).
- كل إضافة وتعديل وحذف مسجّل في سجل تدقيق لا يُعدَّل.

## هيكل المشروع
```
supabase/migrations/   الجداول والحمايات والدوال والتقارير (المصدر)
supabase/setup.sql     كل الـ migrations في ملف واحد للتشغيل الأول
lib/                   الاتصال، التنسيق، التفقيط، بناء أسطر السندات
components/            الواجهة المشتركة، المنتقيات، كشف الحساب، لوحات الإدارة
app/(auth)             الدخول والتسجيل واستعادة كلمة المرور
app/(app)              الشاشات: الرئيسية، السندات، الصناديق، الديون، الأشخاص، الدليل، التقارير، الإدارة
tests/                 اختبارات الوحدة وقاعدة البيانات والاختبار التشغيلي في المتصفح
```

## الاختبارات
```bash
npm test          # اختبارات المنطق (التفقيط، بناء السندات، الأقساط)
npm run test:db   # 21 اختبار على Postgres محلي: الترحيل، العكس، الإقفال، الديون، العملات، العزل والصلاحيات
```
`tests/e2e/` يحتوي بيئة Supabase محلية مصغّرة ورحلة مستخدم كاملة في متصفح حقيقي.

## المراحل القادمة (حسب الخطة المتفق عليها)
- **المرحلة الثانية:** فواتير المبيعات والمشتريات بضريبة القيمة المضافة ورمز QR، المرتجعات، إقرار الضريبة، الجمعيات بجدول الأدوار، بطاقات الائتمان بدورة الكشف، استعادة النسخة الاحتياطية من داخل البرنامج، المرفقات (صور الإيصالات).
- **المرحلة الثالثة:** الزكاة بالحول والنصاب، التنبؤ بالسيولة 90 يوماً، الميزانية الشهرية وأهداف الادخار، القيود المتكررة الآلية، الإدخال بلغة طبيعية، التسوية البنكية باستيراد كشف البنك.
